# Data Dictionary

## Employee Table

| Field | Description |
|---|---|
| EmployeeID | Unique employee identifier |
| Department | Employee's organizational department |
| Education | Highest listed education level |
| Years at company | Employee tenure in years |
| Number of annual trainings attended | Count of annual training sessions attended |
| Years since last promotion | Years elapsed since the employee's last promotion |
| Years with current supervisor | Years working with the current supervisor |
| Employment level | Entry, middle, or upper employment level |
| FT/PT | Full-time or part-time classification |
| Benefits | Benefits-enrollment status |
| Work Arrangement | Hybrid, in-person, or remote arrangement |
| Zip code | Employee ZIP code used for geographic analysis |
| Commute Time | Reported commute time |
| Salary | Employee salary |
| Bonus as a percent of salary | Bonus expressed as a percentage of salary |
| Shift Work | Shift-work classification |

## Satisfaction Table

| Field | Description |
|---|---|
| SurveyID | Unique survey-response identifier |
| Date of survey | Date the response was recorded |
| Employee ID | Employee identifier linked to the employee table |
| Satisfaction Score | Overall satisfaction score |
| Most Satisfied with | Workplace category receiving the most favorable response |
| Least satisfied with | Workplace category receiving the least favorable response |
| Satisfaction with Bonus | Satisfaction score specifically related to bonus compensation |
